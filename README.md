# 大肥鱼显示测试

独立的 AIUI 真机显示实验，当前版本 0.2.0，画布 480×320。不请求相机、位置、麦克风或模型权限，不覆盖现有义眼应用。

本机 HTML 原型（霓潮精简版、完整玩法版、全息动画预览）已在 0.8.5 之后移除，需要回溯时查 Git 历史（提交 c330577 及以前）。

## Canvas 缓存播放（当前默认）

默认打开 `pages/canvas/index`，使用 A 首版绿线、204px 高度、动态播放。单击切换 A/B，前滑切换尺寸，后滑暂停或继续，双击请求退出。原图片组件切帧页 `pages/index/index` 保留作对照。

构建时将原始帧缩放为最高显示尺寸 180×240，导出保留透明度的非预乘 RGBA，编码到 `lib/frame-data.js`。运行时一次性解码 16 帧，通过 `createImageData` / `putImageData` 写入 16 个离屏 Canvas；所有缓存完成后再开始播放。当前页面没有 `<image>` 节点，播放期间不切换 `src`、不加载 PNG、不重新解码或创建动作画布。

每次换帧在同一页面 Canvas 同步执行清除与 `drawImage(已缓存Canvas, ...)`，完整帧绘制后只调用一次 `flush()`。不通过 `setData` 逐帧更新模板；模板只在初始化、操作或状态变化时更新。隐藏时停止播放，重现时复用缓存，卸载时释放引用。

`npm run prepare:canvas` 准备 RGBA 缓存资源。`npm run check` 检查两页与生成资源；`npm run pack` 生成 `dist/dafeiyu-display-lab-0.2.0.aix`；`npm run install` 安装并打开 Canvas 页。运行 `node scripts/aix.mjs launch --page pages/index/index` 可打开原图片切帧页。

## 2026-11-12 内存检查

同一 RG_glasses 在 Canvas 动画仍持续播放时进行只读检查。设备树两段内存区间总计 1979MiB（约 1.93GiB，约 2GB 级），内核 MemTotal 为 1,816,600KiB，即 1774MiB / 1.73GiB；内存区间总和不等同于已经核对厂商标称 DRAM 容量。

采样 MemAvailable 约 787–790.5MiB；AIUI 共享宿主 PSS 约 223–229MiB，不能作为此桌宠独立占用。系统为 low_ram 配置，Java 普通堆增长上限 256MiB、large heap 配置 512MiB；这些数值不是已经验证的独立 AIUI JavaScript / 原生 Canvas 可用上限。

ZRAM 逻辑容量 1536MiB，已交换约 298.5MiB，压缩后物理占用约 111MiB；交换容量不能加算为额外物理 RAM。内存压力 PSI 的 10 / 60 / 300 秒平均值均为 0，已检查的近期日志未出现 OOM 或低内存杀进程记录。这是当前运行快照，未进行耗尽内存的压力测试。

180×240 RGBA 每帧 172800 字节：8 帧约 1.32MiB，16 帧约 2.64MiB，100 帧约 16.48MiB，仅指原始像素，另有编码字符串、临时数据和运行时占用。现阶段建议将解码动作缓存预算设为 10–20MiB、按需切换和释放；这是开发预算，不是设备上限。绿线与填充图在相同尺寸和 RGBA 格式下具有相同的原始像素占用。

原始证据位于 `build/device-evidence/memory-20261112-012022/`，包含系统内存、AIUI 宿主、ZRAM、配置与 Canvas 日志。设备树区间的后续核对值为基址 0x80000000 / 长度 0x68e00000，基址 0xe9f00000 / 长度 0x12d00000，地址与长度各为两个 32 位 cell。

## 眼镜操作
