# 霓潮：一会儿的陪伴

## 已收敛的产品

只有「聊一句、看一眼、成就」三个入口。没有能量、喂食、货币、路线、背包、装饰、长期记忆或每日任务。不要求用户养成打卡习惯。

一次体验：打开看见大肥鱼 → 随口聊一句，或者主动看一件东西 → 接着聊 → 偶尔点亮成就 → 离开。

四个成就：初次接通（完成对话）、共享视线（观察成功）、聊到一起（接着已观察的物体聊）、晚安信号（互道晚安）。每个只解锁一次，不给货币，不反复弹奖励。

## 上下文与存档

- 本次最多保留最近六轮完整对话；这是产品选择，不是模型硬限制。请求取消、失败不进入后续上下文，不给成就。
- 隐藏、离开或重新聊起就清空聊天；不做摘要、不建立用户画像、不存照片。宿主可能保留旧实例，应用自己结束会话。
- 持久化只有 `{version:1,unlocked:["hello","look",...]}`，四个允许的ID。当前无需保存内容、时间线或偏好。
- 成就保存失败有提示与重试；多窗口以事务合并成就，不覆盖既有进度。
- 旧完整原型及其 IndexedDB / localStorage 存档保留，既不搬进新存档，也不删除。用户若要回看可打开 `/web/full-prototype.html`。

## 显示与能力预算

- 当前项目480×320逻辑画布；角色A首版绿线，预缓存8帧180×240离屏Canvas，约1.32MiB RGBA像素。不加载四张家园/旅行大图，不缓存B方案。
- 一个主画面和一个成就弹层。眼镜只显示一行状态、当前短句和少量选择项；电脑对话侧栏仅用于内容迭代。
- 原则上只有一次模型请求在途。主动看一眼才拍一张，禁止为了四个成就引入连续视觉、框选、追踪或后台采集。
- 迁移时仅用眼镜内置LanguageModel；用已支持的工具事件表示成就信号，应用校验并去重保存。工具事件没有文字时给对应本地反馈。
- 模型或手机链路不可用时角色仍待机，提示稍后重试；没有回答不授予成就。

## 当前交付边界

默认本机入口已实现上述流程，文本、物体识别和成就语义触发为明确标注的演示规则。没有连接真实相机、语音或在线模型。最近六轮上下文与成就存档代码在 `lib/pocket.js`；浏览器资源和存储只在 `web/pocket-*`。

独立AIUI诊断已验证：同会话回忆、新空白会话隔离、显式补入历史、8,376字符上下文、晚安工具事件、成就关闭后保留，以及重启后测试记录与全部安装包保留。结果不等同于正式桌宠已完成设备集成，详见 `../docs/RUNTIME-20261112.md`。

本机检查：`npm run test:web`、`npm run test:browser`；保留原显示页检查 `npm run check`。旧原型回溯检查 `npm run test:archive`。
