## 完整循环

1. **家园照料**：问候获得羁绊、心情与少量潮汐币；每分钟最多领取一次问候收益。喂饭团补充能量，吃饱时不浪费饭团；小憩两分钟恢复能量。离开浏览器不会惩罚心情，家中能量按小时缓慢恢复。
2. **眼前共感**：选择毛绒玩具、杯子、绿植、键盘或书，进行共感观察，再主动收集灵感。每种灵感首次领取3枚潮汐币；杯子额外送一份饭团。重复观察会保留相见次数，并影响她的回忆，但不能重复刷首遇奖励。
3. **打包远游**：选择目的地，准备足够的饭团、能量和可选灵感。随身灵感不消耗，归来额外增加2枚潮汐币。饭团不足时，可在补给站用4币购买一份。
4. **归来拆包**：旅行按实际时间进行，关页后仍可归来。到家先保留待拆旅行包，玩家领取后才发放潮汐币、明信片和纪念品。同一旅行包不能重复领取。
5. **远方成为家园**：纪念品可摆放或收起，并实时出现在家园 Canvas。三个目的地各有一幅原创明信片和独立旅行手记。
6. **相伴成为记忆**：观察、照料、出发、手记和心愿会留下记录。可以搜索、分类、置顶、在画布上回看，也可手动告诉她需要记住的偏好。“回忆一下”会引用个人偏好、置顶回忆或最熟悉的物体。

## 存档

当前格式为 version 2，使用 IndexedDB 保存全部回忆、偏好、钱包、饭团、物体相见记录、灵感、旅行、明信片、纪念品、家园布置和心愿进度。不再固定截断为最近100条。时间线每次渲染24条，可继续加载和搜索；已测试1200条回忆导入、刷新恢复与分页。

初版 localStorage 的 version 1 存档会在首次打开时迁移，原始键保留。数据库有 main / backup 两个快照槽，写入使用原子事务和修订号检查；旧窗口不能覆盖新窗口已经保存的状态。发生冲突时暂停旧窗口，刷新后恢复最新存档。

存档属于当前浏览器与网址，清理浏览器数据会删除。可在“本机实验室”导出 JSON；导入支持 v1/v2，格式不支持时不会替换当前记录。个人偏好、模拟观察和虚拟旅行的来源分别记录，不将游戏记录当作真实硬件识别证据。

## 操作与本机实验室

页面上的按钮和 Canvas 共用同一套状态逻辑。画布聚焦后，↑/↓选择，Enter配对确认，Escape返回或取消观察。切后台会停止绘制并取消未完成的观察，返回前台不会接收旧响应。

左下“本机实验室”可以切换单绿/全景、A/B角色、尺寸、固定首帧、识别失败、镜腿模拟，或推进五分钟检查离线结算。推进时钟仅用于当前本机演练会话，不把它当作真实世界时间。

## 美术与画面

新增原创家园与三张旅行场景，使用内置 image_gen 生成。源 PNG、页面优化 JPG、完整提示词和来源说明位于 `web/assets/art/`，清单为 `manifest.json`。图标是本项目绘制的 SVG 符号集。

角色保留此前只参考三视图重新生成的动作帧，不复用他人的动作组。休息、呼吸、旅行位移和光效由本机代码编排。

逻辑坐标仍为480×320。浏览器根据显示尺寸提高后台绘制分辨率，以减少放大模糊，场景与角色初始化后绘入缓存 Canvas，播放时不更换图片组件。当前本机使用384×512原始角色缓存，16帧像素约12MiB；4幅1200×800场景的像素约14.65MiB，另有画布和浏览器开销。这不是眼镜上已验收的内存指标，眼镜0.2.0仍使用180×240缓存。完整彩色家园也不代表单绿眼镜可以呈现相同色彩。
