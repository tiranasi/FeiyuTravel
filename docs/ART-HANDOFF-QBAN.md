# 旅行肥鱼 Q 版动画素材：清单与绘制交接（2026-11-12）

本文档给负责出图的模型（ChatGPT 图像生成）使用，也给之后接收素材的开发代理使用。

- **第 1～2 节**：给你自己看，说明怎么用。
- **第 3 节**：整段复制给 ChatGPT，作为每次对话的第一条消息。
- **第 4 节**：按批次逐条发送。
- **第 6 节**：写给接收素材的开发代理。

---

## 1. 使用方式

1. 每开一个新对话，先上传角色原稿 `output/references/dafeiyu-20261112/character-standard.png`。它在本仓库的上一级目录，是用户提供的 Q 版三视图。
2. 粘贴第 3 节的「总设定」，等它回复确认。
3. **先只画批次 A（基础三视图）**。你确认满意后，把批次 A 的成图也作为参考图上传，再画其他批次。之后每张图都同时参考原稿和批次 A，这样角色比例和线条粗细才能保持一致。
4. 每次只发一个批次的提示词，一张图对应一个批次（最多 8 格）。格子太多时，模型容易画错数量、画乱比例。
5. 不满意的单格可以要求单独重画，并说明「保持与 A 批次相同的头身比、线宽、填色亮度」。
6. 成图按第 5 节命名，放进 `output/references/dafeiyu-20261112/qban-v2/`。

优先级：**P0** 现有代码马上能用；**P1** 体感（IMU）互动和瞬移；**P2** 旅行、明信片和道具。建议按 A → B → E1 → C → E2 → D → F → G → H 的顺序画。

## 2. 为什么是「黑底绿线加淡填色」

眼镜显示屏只有一种绿色（#40FF5E），黑色等于透明，越亮越挡住现实。所以素材直接画成镜片上的最终效果：

- **外轮廓最亮**：在小尺寸下也能认出她。
- **内部是暗绿平涂**：有体积感，又能透出背后的现实。
- **不要发光、模糊、渐变光晕**：缩小以后会变成一团雾。扫描线、闪烁、溶解等全息效果由游戏程序叠加，图里不要画。

最终尺寸很小：全身图约 126px 高，胸像约 196px 高。所以细节必须**粗、少、清楚**。

## 3. 总设定（每个新对话的第一条消息，整段复制）

```
你是这个项目的角色动画原画师。我上传的图是原创角色「大肥鱼」的 Q 版设定图（上排正面、侧面、背面，下排四个表情胸像）。接下来我会分批请你画她的动作和表情素材，用于一款 AR 眼镜上的桌宠游戏。请严格遵守以下设定，每张图都要遵守，不需要我重复。

【角色锁定——必须与设定图一致】
- 约 2.2 头身的 Q 版女孩，头大身小，脸圆，大眼睛（瞳孔里有星形高光），表情软萌。
- 头发：非常长的波浪卷发，几乎垂到小腿；头顶一根弯曲的呆毛；刘海遮住部分额头，侧边有几缕垂发。
- 头饰：白色荷叶边女仆头箍；头部两侧各有一只像鲸鱼鳍一样的耳鳍（上深下浅、边缘带羽状褶）；画面右侧（她的左侧）耳鳍上方有一个小蝴蝶结。
- 服装：深色长袖连衣裙女仆装，白色荷叶边围裙，围裙中央有一个小鲸鱼图案；领口有蝴蝶结和圆形胸针；裙摆下有一圈荷叶边；袖口荷叶边。
- 白色荷叶边短袜，圆头玛丽珍鞋。
- 身后有一条鲸鱼尾巴，从裙后伸出，尾鳍在一侧向上翘。
- 不要改变发型、服装和尾巴，不要加帽子、背包等设定外的物件，除非提示词明确要求。

【画风——线稿加淡填色，直接画成眼镜上的显示效果】
- 背景：纯黑 #000000，整张图没有任何其他背景元素。
- 只用一种颜色：绿色 #40FF5E 的不同亮度。不要出现任何其他色相。
- 外轮廓线：100% 亮度，粗线（在 512px 格子里约 5–6px），连续封闭。
- 内部结构线（五官、发缕、衣褶、荷叶边）：约 70% 亮度，中等粗细（约 3px），只画主要结构，发缕最多 5–6 束大块，荷叶边简化成整齐的波浪边。
- 填色：平涂的暗绿色，不要写实明暗。参考亮度：皮肤约 10%，头发约 18%，深色裙子约 14%，白色围裙/荷叶边/袜子约 28%，耳鳍浅色部分约 24%。
- 眼睛：虹膜约 35% 亮度，瞳孔高光和星形高光 100%，要清楚可辨。
- 腮红用 2–3 道短斜线表示，约 50% 亮度，不要用模糊色块。
- 禁止：发光/外发光/辉光、模糊、柔边、渐变光晕、投影、地面阴影、扫描线、噪点、纹理、背景、边框、文字、水印、签名。
- 禁止画漫画符号（♪、z、汗滴、爱心等）——这些由游戏程序添加。除非提示词明确要求。

【版式与技术规格】
- 画布 2048×1024，均分为 4 列 × 2 行，每格 512×512。不要画格子线，只是按这个网格摆放。
- 每格只画一个姿势，姿势之间至少留 24px 黑色空隙，任何部分（包括头发、尾巴）不能越出自己的格子或和相邻格重叠。
- 全身图：角色总高约 400px（含呆毛），脚底统一落在格子内 y=480 的水平线上（跳跃姿势除外），水平居中。所有全身格的头部大小必须一致。
- 胸像：头顶在格子内 y≈40，胸部下沿被格子底边截断，水平居中，所有胸像格的头部大小一致。
- 侧面姿势一律朝画面右侧（游戏会镜像得到朝左）。
- 格子数量少于 8 时，剩余格子保持纯黑。
- 每格从左到右、从上到下编号 1–8，按我给的编号顺序摆放。

确认理解后只回复「已锁定设定」，然后等我发第一个批次。
```

## 5. 交付与命名

- 每个批次一张 PNG，命名为 `lvfy-qban-<批次>.png`，例如 `lvfy-qban-A.png`、`lvfy-qban-C1.png`。
- 某一格重画时，单独存成 `lvfy-qban-<批次>-<格号>.png`，例如 `lvfy-qban-E1-7.png`，开发代理会用它替换原格。
- 全部放在 `output/references/dafeiyu-20261112/qban-v2/`，不要覆盖原稿 `character-standard.png`。

### 验收清单（每张图都要过一遍）

- [ ] 背景纯黑，没有其他色相（放大看边缘，有没有蓝色、白色残留）
- [ ] 角色特征齐全：呆毛、耳鳍、蝴蝶结（她的左侧）、围裙鲸鱼图案、鲸鱼尾巴
- [ ] 同批次所有格的头部大小一致，全身格脚底在同一高度
- [ ] 外轮廓线明显比内部线亮、比内部线粗；填色是暗绿，不是亮绿
- [ ] 没有发光、模糊、投影、文字、漫画符号（明确要求的除外）
- [ ] 每格互不重叠、不越界，格数和编号顺序正确
- [ ] 缩小检查：把图缩到每格约 128px 宽，还能认出动作和表情

## 6. 给接收素材的开发代理

- **美术约束不变**：游戏内互动画面里的角色只能来自用户确认的 Q 版素材。载入页的成年全息线稿保持原样，不由本批次替换。
- **转换**：新素材是黑底单色，不需要 `bgmask` 去白底。亮度直接取 `max(R,G,B)`，再按格子网格裁切：全身取格子 512×512，按非零像素的包围盒裁剪，再缩放到 126px 高；胸像缩放到 196px 高，并沿用 `fade` 让底边淡出。
  - 全身格的缩放要用**统一比例**（按 `body_front` 的高度计算），不能每格各自缩放到 126px。否则跳跃、蹲下、坐姿的角色大小会不一致。可以只记录脚底基线偏移，不要逐格归一化。
  - 新增一段读取 `qban-v2/` 的转换路径，保留旧的 `character-standard.png` 路径作对照。
- **镜像**：侧面类素材生成 `L` 镜像。有明确左右区别的素材（`bust_tilt_left/right`、`peek_edge`）不要用镜像代替。
- **体积**：每个全身精灵约 126×90 单通道，约 11KB，base64 后约 15KB；胸像约 40KB。全部 80 格约 1.5–2MB 的 base64，会拉长首屏解码时间。建议：
  - P0 素材随包加载。
  - P1/P2 按需分组解码，或者只在进入对应画面时才解码。
  - 解码依然走现有的分块预算。
  - 上真机检查首帧耗时和内存。
- **渲染**：不要用 `ctx.rotate / scale / transform` 来做歪头、翻转。所有角度变化都用预生成素材，Canvas 方法白名单见 `docs/LVFEIYU.md`。
- **体感互动**：`nod` 和 `shake` 事件在 0.4.0 真机日志中出现过。歪头、转头、抬头需要基于 `AbsoluteOrientationSensor` 的姿态角，阈值、保持时间和冷却时间都要先用只记录日志的版本让佩戴者试用后再定。
- **光学观感**：截图只能证明像素。填色亮度是否合适，由佩戴者在镜片上判断；如果偏亮，在转换时统一压低填充亮度，不要退回让模型重画。
