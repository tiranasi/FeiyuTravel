## 画面流程

0. **游戏首页**（0.4.0）：她背对你站在栏杆前眺望远方的行星，右侧是标题、存档状态（在等你 / 旅行中 / 带着礼物回来了）和三个入口：进入游戏、教程、设置（0.6.1 起为弹窗，含语音播报与快速旅行）。新存档默认停在“教程”，看完教程后默认停在“进入游戏”。返回操作统一为双击镜腿（真机上表现为两次 GlobalHook 后送达 Backspace）：首页双击退出应用；主页双击回到首页。在首页或教程中语音唤醒，会直接进入载入，随后她瞬移过来开始聆听。首页期间精灵在后台解码。
0. **教程**（0.4.0）：共六步，每一步都要做出真实操作才能过关，不能连点跳过。依次是：初次见面（单击）、切换选项（滑两下）、双击返回（双击镜腿）、呼唤、旅行、鳞光。每步左侧有 Q 版演示动画，右侧文字逐字打出，同时朗读。中途双击镜腿回到首页，不记录完成；最后一步会记录 `tutorialDone`，然后进入载入动画。
1. **载入**：CRT 开机线 → 汉字雨与透视网格 → 扫描光束逐行显出托腮倚栏的全息大肥鱼（用户批准的成年线稿，只用于载入页）→ 标题错位字、载入日志与分段进度条。进度条取“精灵解码进度”与“演出时间轴”的较小值，至少播放 4.6 秒。
2. **主页**：Q 版大肥鱼站在四个角落之一的投影台上，随机切换行为，每 6–14 秒切换一次：发呆、眺望（背影＋侧身回望）、追泡泡（左右跳跃、转圈）、打盹（z 字）、哼歌（♪）、挥手。偶尔冒出一句自言自语。连续两个行为后有 60% 概率溶解传送到另一个角落。
3. **呼唤**：按“呼唤”或用语音唤醒，她溶解并沿光点弧线瞬移到近处，变成胸像全息投影，可以说话、看看、摸头、戳戳，也可以让她“回去吧”。胸像有开心、得意、生气、委屈、惊讶、思考、疑惑七种心情，由模型回复的心情标签切换；另有聆听、说话口型、摸头、戳戳后的哼/晕、点头、歪头、深夜犯困等帧。
3. **看看**（0.5.0）：底栏选“看看”单击。画面中央留空，只画四角取景框、对焦进度与“咔嚓”闪光，然后扫描线“识别中”。拍到的图交给视觉模型，她用 8 帧“发现”动画（凑近 → 指向 → 说话循环）报出画面中央的主要物体并评论一句，奖励按聊天计。取景或识别中双击镜腿取消（“那就不看啦”）；没有相机权限、离线、超时、看不清各有台词。
3. **旅行通话**（0.6.0）：她旅行时选“通话”（或语音唤醒）。先播 1.8 秒拨号动画（远方地点沿虚线弧飞来的信号点、扩散环、雪花噪点），再从底部信标的光锥里显出全息胸像。左上显示地点、信号格、通话时长和剩余次数。底栏只有说话、看看、挂断，摸不到也戳不到。详见下文“旅行通话”。
4. **行囊 / 商店 / 明信片 / 图鉴**：切角面板菜单。明信片页显示该句文案对应的插画（0.7.0）并叠加动效；插画解码完成前显示程序化线稿场景加 Q 版姿态和一条“冲印”扫描线，完成后 380ms 淡入。
5. **礼物**：她回家时光束落地，展示纪念品、稀有度和鳞光奖励。

所有互动画面中的角色都来自用户确认的黑底绿色 Q 版原画（`../output/references/dafeiyu-20261112/qban-v2/`，选用版本见其 manifest.json；“看看”动画来自 `extensions/photo-discover-8f/`）。转换只取亮度（max(R,G,B)，低于 18 视为噪点），不改色。所有全身帧按站立身高 415px 统一缩放到 126px，脚底对齐到图像底边；胸像、图标、发现动画各自统一比例。侧向帧原画朝右，朝左时运行时水平镜像。

精灵分两批解码：载入页只等 10 个基础帧（全息像、正侧背、五个胸像）；其余 78 帧进入游戏后按每帧 6ms 预算后台解码，未就绪时场景回退到基础帧。

## 语音播报（TTS，0.4.0）

- **实现**：页面适配器优先使用 `speechSynthesis.synthesize()` 加 `SpeechAudioPlayer`，失败时退回 `speak(..., 'immediate')`。音色 `female-tianmei`，音量 3（文档范围 0–10，默认 1）。
- **朗读内容**：呼唤招呼、摸头和戳戳、聊天回复、没听清、告别、旅行归来、教程每一步、开启语音的提示。主页的自言自语只显示文字，不出声。
- **防止录进自己的声音**：开始聆听前一定先停播。语音唤醒后马上就要聆听，所以这时不朗读招呼语。测试会断言聆听从不发生在播放中。
- **停播时机**：页面隐藏、卸载、回到首页或进入载入时都会停播。
- **文本清理**：`speechText` 去掉心情标签、♪、「」和表情，把“…”换成逗号，最多 60 字。
- **开关**：首页的“语音：开/关”，保存在存档 `settings.voice` 中。
- **朗读指示**：对话气泡上方的跳动短条按字数估计时长，因为真机播放器拿不到可靠的进度。

## 点头呼唤（0.4.0）

页面在加载时调用 `enableWorldAwareness()`。`onHeadGesture` 收到 `nod` 时：在主页呼唤她，在首页相当于确认。所有收到的手势都会写进日志。真机还没有验证点头事件能否送达，所以教程里不教这个操作。

## 看看：相机与视觉模型（0.5.0）

实现移植自一眼顶真（只读参考，未改动该项目），在 `lib/camera.js`：

- **拍照**：`getUserMedia({video:true})` → `new ImageCapture(track)` → 预热 2500ms → 无参数 `takePhoto()` → `arrayBuffer()`；拿不到时退回 `wx.media.createCameraContext`。拍完停掉 track。必须在按键回调里同步发起。
- **压缩**：最长边 1024、质量 0.7，转成 data URL。
- **识图**：每次新建模型会话，`session.prompt([{role:'user',content:[文本, image_url]}])`，30 秒超时，用完销毁。提示词 `visionPrompt`：以大肥鱼口吻、第一人称看相机画面，说出中央主要物体加一句可爱评论，不超过 40 字，看不清用 [疑惑]，不编造。
- **动画**：发现帧 1–5 为凑近到指向（180/110/100/100/280ms），之后在 5–8 间循环说话；至少停留 7 秒或朗读结束后 1.5 秒，然后回到胸像。
- **本机预览**：不打开电脑摄像头，2.8 秒后给固定回答，只用来检查动画与布局。

## 旅行通话（0.6.0）

- **次数与时长**：每次旅行 `CALLS_PER_TRIP = 3` 次，记在存档 `trip.calls`；一次最长 2.5 分钟真实时间（`CALL_MAX_MS`），到时且没在聆听/识图时她说“信号飘走了”，2.4 秒后自动挂断。最后 20 秒信号格变弱、波动加大。
- **挂断**：底栏“挂断”或双击镜腿，她说一句告别（朗读），溶解后回到主页，旅行继续。
- **通话中她到家**：停止聆听与识图，她说“我已经到家门口啦”，2.6 秒后挂断，主页上她以到达光束现身，礼物照常弹出。
- **提示词**：聊天和识图的游戏状态后面追加 `callContext(dest)`：她不在身边、正在某地旅行、通过远程信标通话，并附上该地点的见闻句子。每次开始和结束通话都会丢弃聊天上下文。
- **全息波动渲染**（`lib/draw.js` 的 `holoSprite`）：精灵切成 10 条横带（`STRIP_BANDS`），每条按两层正弦左右错开；另画一层错位残影；整体亮度微闪，偶尔一帧暗到 55%；外加滚动亮带与偶发撕裂。信号越弱，振幅越大（最多 3.5 倍）、暗闪越多。
- **可调参数**：`HOLO = { amp: 3, ghost: 0.22, ghostDx: 3 }`，分别是波动振幅（像素）、残影透明度、残影偏移。波动是否让人不适由佩戴者判断，需要时调小 `amp`。
- **性能做法**：横带在第一次通话时由 `entry.makeStrips()` 预先切好成小离屏 Canvas，扫描线（每 3 行压暗到 45%）直接烘进像素，运行时每条只是一次 5 参数 `drawImage`。最初用 14 次 clip 加整幅重画，真机每帧约 25ms（发现动画 35–40ms）；改成预切横带后约 15–17ms。

## 存档

键名 `lvfeiyu.save.v1`，JSON 字符串，经 `wx.getStorageSync / setStorageSync` 读写。每 15 秒和隐藏时保存一次。`normalize` 会丢弃未知物品、越界数值、不存在的地点和超长文字，坏档时回退到新档。聊天上下文不进存档，页面隐藏时销毁模型会话。调试参数：`{"debug":"fast"}` 让时间加速 120 倍，`{"reset":"1"}` 清空存档。
