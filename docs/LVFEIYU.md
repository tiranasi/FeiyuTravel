# 旅行肥鱼 0.3.0 设计与验证记录（2026-11-12）

住在眼镜里的全息桌宠大肥鱼。本地单机游戏，全部界面文字为中文。玩法属于“放置旅行”类型，内容、角色、地点与数值为本项目原创，不复刻任何既有游戏的角色、美术或关卡。

## 画面流程

1. **载入**：CRT 开机线 → 汉字雨与透视网格 → 扫描光束逐行显出托腮倚栏的全息大肥鱼（用户批准的成年线稿，只用于载入页）→ 标题错位字、载入日志与分段进度条。进度条取“精灵解码进度”与“演出时间轴”的较小值，至少播放 4.6 秒。
2. **主页**：Q 版大肥鱼站在四个角落之一的投影台上，随机切换行为，每 6–14 秒切换一次：发呆、眺望（背影＋侧身回望）、追泡泡（左右跳跃、转圈）、打盹（z 字）、哼歌（♪）、挥手。偶尔冒出一句自言自语。连续两个行为后有 60% 概率溶解传送到另一个角落。
3. **呼唤**：按“呼唤”或用语音唤醒，她溶解并沿光点弧线瞬移到近处，变成胸像全息投影，可以说话、摸头、戳戳，也可以让她“回去吧”。胸像有得意、生气、惊讶、思考四种表情，由模型回复的心情标签切换。
4. **行囊 / 商店 / 明信片 / 图鉴**：切角面板菜单。明信片页用线条程序化绘制六个地点的场景，并放入 Q 版姿态。
5. **礼物**：她回家时光束落地，展示纪念品、稀有度和鳞光奖励。

所有互动画面中的角色都来自用户的 Q 版三视图（正、侧、背和下排四个表情胸像）。侧面另生成水平镜像；没有使用已有动作组。

## 经济（第一版）

| 来源 | 数值 |
| --- | --- |
| 初始 | 120 鳞光、海苔饭团 ×2、浮光贝 1 |
| 浮光贝 | 每 45 分钟长 1 个，最多 4 个；拾取每个 8–20 鳞光 |
| 每日互动 | 摸头 +5 ×3、戳戳 +2 ×2、聊天 +3 ×5，次日重置 |
| 旅行归来 | 近途 20–40、中途 50–90、远途 120–200 鳞光 ＋ 纪念品 |

| 便当 | 价格 | 行程 | 时长 |
| --- | --- | --- | --- |
| 海苔饭团 | 20 | 近途：霓虹夜市 / 雨巷书屋 | 20–45 分钟 |
| 星砂布丁 | 60 | 中途：云顶温室 / 海底电站 | 60–150 分钟 |
| 深海鲷鱼烧 | 150 | 远途：星港码头 / 月面观景台 | 3–6 小时 |

护符：迷途罗盘（40）多寄两张明信片；好运贝壳（80）提高稀有礼物概率。共 6 个地点 × 3 件纪念品 = 18 件图鉴，分普通、珍贵、稀有三档，远途的稀有加成最高。

便当放进行囊后，她会在 1–3 分钟内自己出发（召唤或打开菜单时暂缓）。关闭应用期间也会结算：浮光贝生长、出发、寄回明信片、回家。归来礼物在领取前保存在存档里，下次打开时补弹礼物页。设计目标：每天随手打开几次，约两天能攒出一次远途。

## 存档

键名 `lvfeiyu.save.v1`，JSON 字符串，经 `wx.getStorageSync / setStorageSync` 读写。每 15 秒和隐藏时保存一次。`normalize` 会丢弃未知物品、越界数值、不存在的地点和超长文字，坏档时回退到新档。聊天上下文不进存档，页面隐藏时销毁模型会话。调试参数：`{"debug":"fast"}` 让时间加速 120 倍，`{"reset":"1"}` 清空存档。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `pages/home/index.ink` | AIUI 页面：40ms 帧循环、按键、语音唤醒、语音识别与模型适配、存储适配 |
| `lib/app.js` | 画面状态机与输入，宿主能力全部注入 |
| `lib/game.js` | 纯规则：存档、离线结算、旅行、商店、互动奖励（时间与随机数注入） |
| `lib/content.js` | 中文文案、物品、地点、礼物、心情标签、系统提示词 |
| `lib/scenes.js` / `draw.js` / `postcards.js` | 渲染 |
| `lib/sprites.js` / `sprite-data.js` | 单通道亮度精灵（base64），运行时按帧预算分块解码成离屏 Canvas |
| `tools-art/convert.py` | 从三视图与线稿生成精灵：`PYTHONPATH=build/pylibs python tools-art/convert.py` |
| `web/lvfeiyu.html` | 本机预览外壳（`npm run dev`，`?fast=1`），不打入 AIX |
| `tests/lvfeiyu.test.mjs` | 12 项规则、存档、解码与全流程冒烟测试 |

渲染只用义眼盯真真机上已画出的 Canvas 能力：rgba、globalAlpha、虚线、clip、路径、弧线、贝塞尔曲线、measureText，以及 `drawImage(缓存Canvas, x, y, w, h)`。`npm run check` 会拒绝 `ctx.scale / rect / ellipse / translate / transform` 和 `lighter` 混合；冒烟测试用白名单假 ctx 走完所有画面。
